# Comunicar un problema de seguridad

Usa el [formulario privado de GitHub](https://github.com/luka-duj/falta-un-papel/security/advisories/new) para comunicar posibles vulnerabilidades o filtraciones. Describe el componente, la versión y el efecto con datos ficticios. Omite credenciales, documentos reales y datos personales. Si aún no aparece el formulario, espera a que se habilite el canal privado antes de compartir detalles.

Para un enlace roto, campo incorrecto u otro problema en un trámite, usa la [plantilla de error](https://github.com/luka-duj/falta-un-papel/issues/new?template=error.yml).
