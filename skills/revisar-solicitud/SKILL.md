# Revisar mi solicitud

El resultado es una lista de correcciones para una solicitud que ya existe. Si el usuario pide recibir un PDF nuevo o corregido, pasa a [Falta un papel](../falta-un-papel/SKILL.md) antes de iniciar la revisión. Si solo pide qué debe cambiar, revisa aquí y deja intactos el borrador y los anexos.

1. **Identifica qué se puede revisar.** Reutiliza el borrador, la lista de campos o anexos y el municipio y trámite que la persona ya haya facilitado. Si una omisión impide identificar el trámite o saber qué se ha preparado, agrupa solo lo necesario en una pregunta breve. Empieza por la [guía común de fuentes y privacidad](../falta-un-papel/references/fuentes-y-datos.md). Si el entorno no está habilitado para datos personales, usa etiquetas de campos, estados sin valores y nombres genéricos de documentos. Para un PDF editable, la persona también puede ejecutar [la comprobación local de campos](../falta-un-papel/references/editor-pdf.md#revisar-un-borrador) y compartir solo ese resumen.
2. **Contrasta el borrador con la ficha vigente.** Comprueba la variante, los campos que cambian el trámite, los anexos obligatorios y sus condiciones y, cuando proceda, las instrucciones de firma o presentación. Usa la evidencia disponible de lo que la persona tiene y distingue la presencia de un campo de la validez de su contenido. Si solo puedes confirmar el requisito o el tipo de anexo, deja pendiente si la persona lo cumple. Para PDF planos, escaneados o campos dudosos, comprueba las etiquetas visibles si el entorno lo permite o pide a la persona únicamente el estado del campo relevante. En un formulario web con acceso restringido, deja sin comprobar lo que quede detrás de la identificación.
3. **Devuelve correcciones accionables.** Empieza por **Qué falta o debes corregir**, con los bloqueos de presentación primero. Para cada uno, indica el campo o anexo, qué hacer y la fuente municipal. Usa **Por confirmar** para las condiciones o páginas que no pudiste comprobar. Si no ves bloqueos, delimita qué comprobaste y recuerda el paso de firma o presentación que corresponda. La persona decide si corrige, firma o presenta.
